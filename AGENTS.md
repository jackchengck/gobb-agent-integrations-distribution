This is the public Gobb integrations distribution repository. Never import private repository history, documentation, evidence, credentials or model fixtures. Use ordinary Git Flow: feature/* from current develop; reviewed feature merges into develop with --no-ff; release/* from develop; reviewed release merges into main and back into develop with --no-ff; hotfix/* from main, merged back into main and develop. Keep canonical main clean and use task worktrees. Fetch before selecting a base; preserve unrelated changes and legacy branches. Run scripts/setup-git-flow.sh after cloning once the canonical tracked hook exists; integrate conflicting hooks rather than overwrite them. Never commit directly to main/develop or force-push. Release tags must be immutable and reference an accepted main commit. Push, CI, publication and deployment require their own explicit release scope; the local hook is not server authorization. Export only the reviewed public allowlist. Existing development artifacts are not formal releases.
